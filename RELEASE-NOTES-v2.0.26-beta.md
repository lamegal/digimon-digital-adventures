Digimon Digital Adventures V2 — v2.0.26-beta

Support Qualities, Area Attacks, Tamer turn controls and Digimon Tokens

- Fixed Support BLAST Attacks with Advanced Effect POISON incorrectly requiring an individual target before opening area placement. Legacy and structured Area Tags and older Quality-to-Attack bindings are recognized without applying the Area Tag to unrelated Attacks. Harmful Support Effects default to enemy targeting; Positive Effects default to allies.
- Fixed Support Attacks with Protecting Shield or other fixed supportive Effect grants being rejected as having no Effect Tag when the purchased Quality stored only its Attack binding. Recognition now covers legacy keys, embedded UUIDs and unambiguous saved names after Attack recreation, without requiring an additional Effect purchase or core status icon. Shield application, Temporary Wound Boxes, per-Combat uses and Area restrictions remain enforced.
- Unified special Gain Force Attack bindings with the same resolver, fixing Zero Unit failing to open its own Support activation for legacy string selections, embedded UUIDs or recreated Attack IDs. Zero Unit's evolution and revival benefits do not require a separate Effect Tag. Verified Inspiring Guidance's legacy binding and Guiding Dice after a Positive Effect, and recognition of all 40 catalog Effect options permitted on Support; the individual Quality requirements still apply.
- Fixed Code Wizard's DAMAGE-Tag exception being ignored by the declaration validator and evolution/form wizard. Eligible purchased Effects such as BURN, FREEZE and DOT can now be selected and declared on Support Attacks. The post-creation browser also recognizes canonical and localized specialization choices.
- Fixed Status Warlord confusing any Quality Tag or Signature Move with an Effect Tag. Its Support/Damage pair now permits otherwise eligible Weapon, Area and Signature Attacks while still excluding Effect-bearing Damage Attacks, including Effects stored only in purchased Quality bindings.
- Fixed Holy Ward and Dark Emblem omitting eligible Effect categories from their trigger lists and remaining blocked after their first use. Their once-per-Round use resets correctly. Chaotic Balance's alternate-use restriction and bonus apply across consecutive Rounds, expire after a skipped Round and do not carry into a new Combat. Inspiring Guidance now grants dice only after a Positive Effect actually applies to an allied Support target; denied Effects grant no dice, and Area use still selects one beneficiary.
- Fixed Zoner ignoring legacy string choices or Area Tags already saved on the Attack. Firewall Bypass preserves Support Area Potency and Duration only when targeting everyone. Friendly Fire converts the enemy portion to Damage only for an eligible supportive Effect and suppresses that Effect for enemies; harmful Support Effects such as POISON are not incorrectly converted, including when old copied tags disagree with the current purchase.
- Corrected area preview geometry and target intersection for BLAST, BURST, CONE, LINE, PASS and WAVE. BURST follows the caster's occupied footprint, including larger Tokens, square and hex grids, and gridless maps. CONE uses a 90-degree cone anchored to the Token's edge. LINE supports its permitted width, and LINE/CONE origins remain aligned during mouse and wheel rotation. WAVE remains square at every rotation, including its Base Size region. PASS represents the swept footprint and no longer advances the caster by an extra edge offset. BLAST placement uses grid Spaces and catches partial intersections with larger Tokens.
- Fixed End Turn on the Tamer sheet, with protection against duplicate clicks and retry after a failed request.
- Fixed Digivolution and regression restoring the wrong Token dimensions or mesh scale. Each destination form uses its own grid size; automatic forms do not inherit the outgoing form's manual override. Prototype and placed Token dimensions, selection geometry and interaction footprint are synchronized, including observing clients.
- Fixed incompatible native movement trails retaining a previous form's 2x2 footprint after regression to 1x1. A trail with different dimensions is cleared and the ruler is refreshed while DDA Movement expenditure and Action accounting are preserved. Clearing that native trail also clears the core movement undo associated with it; matching trails are retained.
- Fixed newly created Partners, including Blucomon, missing their official Token art when the creating player cannot browse Foundry's file directories. Shipped Token images resolve from the bundled index with exact path casing. Creation sets linked Token dimensions, preserves manually selected art, and repairs placeholder image fallbacks.
- Added optional Script macros to repair an existing Partner's official Token art, refresh only its current footprint, or collect a read-only footprint diagnostic.
- Retained the previous quality-rank, multiplayer Dodge and advisory DP-budget fixes. LINE wall bounces remain manual.

Validation: 133 automated tests passed, plus 83 wizard/progression regression assertions, using production modules with simulated Foundry/PIXI APIs. The Support Quality tests include actual binding, declaration, Effect application, Temporary Wound, use-ledger, Guiding Dice, Zero Unit, Ward/Emblem and Area modules, the creation/form wizard and post-creation browser, plus the live Quality catalog. An existing Blucomon was reported fixed in a live game using the footprint repair macro; full live multiplayer validation across other species remains pending.

Compatibility: Foundry Virtual Tabletop v13. Publish this version as a GitHub pre-release.
